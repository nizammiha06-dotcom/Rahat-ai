# Rahat AI

A Kotlin + Jetpack Compose Android AI assistant starter project.

## Build APK with GitHub Actions
1. Upload the contents of this project to your GitHub repository (keep folder paths).
2. Open **Actions** and enable workflows if prompted.
3. Run **Android APK Build** from the Actions tab, or push a commit.
4. Open the successful workflow run and download the `Rahat-AI-debug-apk` artifact.

## Important
This is a buildable starter scaffold, not a claim that every cross-app automation feature is already implemented. Android restricts some capabilities. Accessibility automation, screen capture, notification access, background microphone, and third-party app workflows must be implemented and tested individually. Do not use this app to automate banking/security apps or handle OTPs/passwords/payment approvals.
